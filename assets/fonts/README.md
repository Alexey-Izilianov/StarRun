# Exo 2

Источник: [официальный репозиторий Google Fonts](https://github.com/google/fonts/tree/main/ofl/exo2).
Файл `Exo2.ttf` — оригинальный `Exo2[wght].ttf` (переменная насыщенность), переименован только файл.
Семейство и содержимое шрифта не изменены. Используется для всего игрового текста, включая кириллицу.
