# 1. Техническое задание на разработку

# 2. Основное

- Автоматическая стрельба
- Персонажем можно управлять через - WASD
- Врагов становится все больше к концу волны
- С убитых врагов выпадает опыт, персонаж его подбирает
- Одна волна должна длиться 12 - 18 минут
- У персонажа есть уровень

# 3. Сеттинг

- Сеттинг в стиле Звезного десанта, но не под копирку, можно использовать как референс

- Основной персонаж - морской пехотинец.
- Враги - различные жуки
- Карты будут разные по биомам
- На каждой карте будет лес, который можно будет прорубать

## 3.1 Визуальный стиль

- Вид сверху (top-down) - 2D
- При убийстве жуков они издают звук и из них вытекает зеленая жидкость

## 3.2 Звук и музыка

- Военный марш (эпический, орекстровый)
- Выстрелы, взрывы, крики жуков
- Фоновый шум, разный для каждой локации
- Несколько голосовых фраз десантника

# 4. Ядро геймлея

## 4.1 Управление

- WASD / стрелки - движение
- Пробел - активная способность
- Мышь для управления в меню и выбора улучшений
- Esc - пауза
- Tab - открытие меню статистики персонажа

## 4.2 Основной игровой цикл

Спавн - Движение - авто - атака - Убийство жуков - получение опыта\ресурсов - улучшение - появление более сильных врагов - появление боса в конце - эвакуация

## 4.3 Тайилайн сессии

В игре должа быть динамическая сессия которая должна висить от других факторов

## 4.4 Враги - жуки

- Рабочий - 10 ХП - Медленный - урон - 5   Особенность - их очень много
- Воин    - 30 ХП - Быстрый   - урон - 15  Особенность - Долгий замах
- Стрелок - 20 ХП - Средний   - урон - 10  Особенность - дист. атака
- Летающий
- Танкер
- Мозговой
- Королева

## 4.5 Прочее

- Враги спавняться вне экрана (за краем камеры)
- Каждую минуту увеличивается количество здоровья и урона
- Каждые 5 минут - выходит полубос

# 5. Оружие и апгрейды

## 5.1 Оружие

- Основное (начальное) оружие - "MAR" - автоматическая винтовка (референсом можно взять модель основного оружия из звездного десанта). Стреляет по прямой траектории.

- Дробовик - открывается позднее по сюжету. Стрелят дробю в небольшом радиусе но с большой площадью

- Снайперская винтовка

- Огнемет

- Тактическая ракетница

- Мини-турель

- Шокер

## 5.2 Система прокачки

При убийстве жуков и добычи ресурсов игрок будет получать опыт, путем собирания кристалов опыта (условно). При повышении уровня игрок получает выбор из 3 апгрейдов. Апгрейды будут открываться постепенно с открытием новых пушек и способностей.

## 5.3 Пассивные апгрейды

- Скорость передвижения
- Увеличение здоровья
- Радиус подбора опыта
- Скорость бега
- Регенерация здоровья
- Шанс уклонения

## 5.4 Апгрейды оружия:

- Увеличение урона конкретного оружия
- Увеличение скорострельности оружия
- Увеличения радиуса взрыва
- Увеличение разброса дроби
- Экспансивные пули
- Больше дроби
- Бронебойные патроны

### 5.4.1 Общие

- Увеличение общего урона
- Увеличение общей дальности полета снаряда
- Увеличение общей скорости перезарядки
- Увеличение общего боезапаса

### 5.4.2 Специальные

MAR - Подствольный гранатамет (Можно найти на карте при иследовании локации)

### 5.4.3 Виды апгрейдов

Каждый пассивный или специальный апгрейд должен иметь различную редкость

- Белый (обычный) - + 7%
- Зелеленый (не обычный) - + 10%
- Синий (редкий) - + 14%
- Фиолетовый
- Желтый
- Красный

## 5.5 Система уровней персонажа

- Убийство врагов дает опыт
- При заполнении шкалы - пауза и выбор апгрейда
- При подборе нового оружия, появляется возможность менять оружие при помощи колесика мыши или нажатием на клавиши 1 - 3
- Максимум 3 оружия.

## 5.6 Мета прогрессия игрока

- После прохождения уровня игрок будет получать валюту за которую можно будет покупать улучшения на базе хабе.

- На базе можно будет докупать спец улучшения для оружия и снаряжения

- Валюту можешь предложить сам, игрок будет добывать собирая ее на карте

# 6 Требования к Архитектуре и технологиям

- Игра должна быть написана на языке Python
- Фреймворк может быть выбран любой, наиболее подходящий
- Необходимо использовать все современные технологии Python
- Основной упор должен быть сделан на оптимизацию проекта, но не в ущерб качеству проекта
- Спланировать к отрисовке 300 - 400 протвников одновременно
- Добиться частоты не менее 60 FPS при разрешении 1080p
- Приложение должно быть легко масштабировать

# 7 Биомы

- Пустыня (Лес в виде кактусов, если подойти в плотную к ним игрок получит урон), есть зыбучие пески при нахождении на которые игрок будет постепенно погружаться в них и замедляться
- Джунгли (Лес в виде тропических деревьев, есть бурные реки через которые нельзя пройти)
- Густой лес (Лес в виде Больших елей)
- Болото (Лес в виде болотистых деревьев)

В биомах должны быть небольшие постройки, дома, агнары, может небольшие гаражи в которые можно будет зайти без предзагрузки (заходить можно будет через окна или двери, соотвественно нужна будет анимация перепрыгивания через окно и забор, а так же открытия дверей)

В каждом биоме должны быть деревья, при подходе к которым у персонажа должна активироваться анимация удара топором, после нескольких ударов, деревья должны рассыпаться и давать возможность персонажу пройти дальше.
Референсом можно взять механику из Дипроск Сюрвайвор.

# 8 Визуал

Игрок должен выглядить как раскаченный десантник, референсом можно взять
главного героя из Gear of War
