## 1. Назначение программы

StarRun — компьютерная игра в жанре top-down выживалки: оператор управляет
десантником, который отстреливается от толп жуков, набирает опыт, выбирает
улучшения и в конце забега уходит на эвакуационном челноке.

**Функции программы (версия 0.0.4):**
- забег длиной 12–18 минут: рост численности и силы жуков, налёты, полубоссы,
  королева, эвакуация;
- карта с лесом под топор, постройками, реками, зыбучим песком и топью;
  четыре биома по кругу; находки на карте;
- восемь видов жуков, у каждого своё поведение;
- движение и бег десантника, автоматическая стрельба, до трёх стволов из семи
  с переключением, модификации стволов, удар с орбиты;
- опыт, уровни, выбор одного из трёх улучшений шести редкостей;
- статистика десантника и итоги забега;
- настройка всех чисел игры в текстовых файлах данных.

**Ограничения версии:**
- графика — простые фигуры, звука нет;
- нет базы между забегами и сохранений; образцы ДНК пока только копятся
  в забеге; все стволы доступны с первого забега (открытие по достижениям —
  с базой, на этапе 5).

## 2. Условия выполнения программы

**Аппаратные средства:**
- процессор x86-64;
- оперативная память — от 4 ГБ;
- видеокарта с поддержкой OpenGL 3.3 (в том числе встроенная);
- клавиатура и мышь.

**Программные средства:**
- Windows 10 или 11, 64 бит;
- для запуска из исходников — [uv](https://docs.astral.sh/uv/) (сам установит
  Python 3.13 и зависимости) либо Python 3.13.

Python 3.14 не подходит: у библиотеки pymunk, от которой зависит Arcade, нет сборок
под эту версию.

## 3. Выполнение программы

### 3.1 Установка и запуск

```bash
git clone https://github.com/Alexey-Izilianov/StarRun.git
cd StarRun
uv sync
uv run starrun
```

Игра открывается на весь экран. Параметры командной строки:

| Параметр | Действие |
|---|---|
| `--windowed` | запуск в окне 1600×900 (размер можно менять) |
| `--seed N` | зерно случайности: тот же N — тот же забег при тех же действиях |
| `--biome ID` | с какого биома начать: `desert` (по умолчанию), `forest`, `jungle`, `swamp`; `plain` — ровная земля без карты |

Клавиша F11 переключает полноэкранный режим и окно в любой момент.

### 3.2 Экран игры

Десантник всегда в центре экрана. По высоте виден участок мира в 1080 пикселей
при любом разрешении монитора; по ширине — сколько позволяют пропорции экрана.

| Где | Что показано |
|---|---|
| Верхний край | Полоса опыта и номер уровня |
| Слева вверху | Здоровье (текущее / наибольшее) и выносливость |
| В центре вверху | Время забега и шкала «Тревога улья»; при королеве — её здоровье; при эвакуации — сколько секунд осталось простоять в зоне |
| Справа вверху | Образцы ДНК, число убитых жуков, подсказка по клавишам |
| Внизу по центру | Слоты оружия 1–3: название, уровень ствола (пять делений; золотые — есть модификация), патроны или «перезарядка»; выбранный слот — в светлой рамке. Справа — слот удара с орбиты с полосой перезарядки |
| У краёв экрана | Стрелки к полубоссу, королеве и зоне эвакуации, если их не видно |
| Под временем | Сообщения о событиях забега (раздел 4) |

**Обозначения в мире:** оливковый круг с наплечниками — десантник (краснеет при
попадании); жуки — см. 3.6; карта и находки — см. 3.5; тёмная точка на жуке — его голова, она смотрит
на десантника. Подсветки жуков: белая вспышка — попадание, оранжевое мерцание —
горит, голубое кольцо — оглушён, розовое кольцо — усилен аурой мозгового.
Голубые точки — кристаллы опыта, зелёные брызги и пятна — кислотная кровь,
жёлто-зелёные шары — плевки стрелков и королевы, оранжевые пятна — горящий напалм,
серые круги со стволом — поставленные турели.

### 3.3 Управление десантником

- **Движение** — WASD или стрелки, в том числе по диагонали.
- **Бег** — удерживать Shift при движении: скорость ×1,6, тратится выносливость.
  Выносливость восстанавливается через 0,8 с после бега.
- **Стрельба** — автоматическая, из выбранного ствола, см. 3.7.
- **Рубка** — идти в дерево: десантник рубит его топором, см. 3.5.
- **Двери** открываются сами перед десантником; через окно и забор он перелезает.
- **Выбор ствола** — клавиши 1, 2, 3 или колесо мыши.
- **Удар с орбиты** — Пробел, метка ставится под курсором мыши.

Жуки не могут пройти сквозь десантника: они упираются в него и кусают.

### 3.4 Ход забега

1. **Высадка.** Жуков немного, они появляются за краем экрана со всех сторон.
2. **Рост давления.** Каждую минуту жуков становится больше (к 12-й минуте — около
   320 на карте), они получают +8 % здоровья и +5 % урона. Новые виды вливаются
   в толпу по одному (3.6). С 40-й по 60-ю секунду
   каждой минуты идёт **налёт** — плотная колонна с одной стороны экрана.
   Отставших жуков рой переносит вперёд по ходу движения, поэтому уйти от толпы
   насовсем нельзя.
3. **Полубоссы** выходят на 5, 10 и 15-й минуте.
4. **Тревога улья** растёт на 5,5 % в минуту и на 5 % за каждого убитого полубосса.
   При 100 %, но не раньше 12-й минуты выходит **королева**.
5. **Эвакуация.** После гибели королевы на карте появляется голубая зона посадки
   (стрелка у края экрана показывает направление) — всегда на открытом месте,
   лес и заборы вокруг неё вырубаются. Челнок забирает десантника,
   когда тот простоит в зоне в сумме 60 секунд; вне зоны таймер стоит. Рой в это
   время давит сильнее.
6. **Итоги.** Эвакуация — победа, гибель десантника — поражение. На экране итогов —
   время, уровень и число убитых; кнопки «Ещё забег» (следующий биом) и «Выйти из игры».

### 3.5 Карта и биомы

Карта — 8000 × 8000 пикселей (200 × 200 клеток по 40 px), по краю — скалы.
Высадка — в центре, на поляне. Биомы идут по кругу: пустыня → густой лес → джунгли →
болото. «Ещё забег» на экране итогов начинает следующий биом, «Начать заново»
в паузе — тот же. Название биома — в сообщении при высадке.

| Биом | Лес | Особенности |
|---|---|---|
| Пустыня | кактусы, ~10 % карты | Кактус колет при касании: 4 урона раз в 0,5 с. Зыбучий песок (светлые пятна с тёмной кромкой и воронками): десантник погружается полностью за 2 с, теряет до 70 % скорости, а погрузившись — 10 урона в секунду; выбирается за секунду. Жуки в песке вдвое медленнее. 6 построек |
| Густой лес | ели, ~42 % | Самый плотный лес; 4 постройки |
| Джунгли | пальмы, ~34 % | Две реки: вода непроходима ни для кого, кроме летающих; мосты через 30–40 клеток; 4 постройки |
| Болото | болотные деревья, ~26 % | Топь на 30 % карты: десантник и наземные жуки на 40 % медленнее; 5 построек |

**Лес.** Деревья не пропускают ни десантника, ни жуков и закрывают линию огня:
стволы не стреляют сквозь лес, автонаведение выбирает только видимых жуков.
Упрись в дерево — десантник рубит его топором, удар раз в 0,4 с: кактус — 2 удара,
пальма и болотное дерево — 3, ель — 4. Подрубленное дерево уменьшается, срубленное
оставляет пень. Лес выжигают взрывы ракет и гранат, удар с орбиты и огнемёт (первое
дерево на струе); танкер проламывает лес и заборы, полубосс и королева — всё под собой.

**Постройки** — модули колонистов: стены, одна-две двери, окна, иногда забор
вокруг двора с воротами.
- Дверь распахивается перед десантником и закрывается за ним.
- Через окно и забор десантник перелезает: скорость ×0,4.
- Крыша скрывает, что внутри; когда десантник внутри — крыша прозрачна.
- Пока десантник снаружи, жуки обходят постройку. Если он укрылся внутри — жуки
  выламывают двери (4 с напора, сообщение «Жуки выломали дверь») и лезут в окна
  втрое медленнее обычного.
- Стены и закрытые двери держат пули и кислоту.

**Находки** — подбираются касанием, отмечены светлым пульсирующим кругом:

| Находка | Вид | Сколько | Действие |
|---|---|---|---|
| Аптечка | белая коробка с красным крестом | 8 | +40 % здоровья |
| Магнит | красная подкова | 3 | Весь лежащий опыт летит к десантнику |
| Образец ДНК | фиолетово-бирюзовая спираль | 10 | +1 к образцам ДНК (тратятся на базе — этап 5) |
| Ящик с оружием | оливковый ящик с жёлтой полосой | по одному в постройке | Новый ствол в свободный слот, сразу в руках; слоты заняты — +30 опыта |
| Подствольный гранатомёт | такой же ящик с золотой полосой | один, в одной из построек | Модификация MAR |

### 3.6 Враги

| Жук | С какой минуты | Как узнать | Чем опасен | Как действовать |
|---|---|---|---|---|
| Рабочий | с начала | Коричневый, мелкий | Толпа, укус раз в секунду | Не давать окружить себя |
| Воин | 2-й | Красный, крупнее | Удар 15 после замаха 0,8 с; вокруг наливается оранжевое кольцо | Отбежать из кольца до конца замаха |
| Стрелок | 4-й | Оливковый, с зелёным мешком сзади | Держится в 320 px, плюётся кислотой; мешок раздувается перед плевком | Сокращать дистанцию или уходить с линии плевка |
| Летающий | 6-й | Светлый, с крыльями и тенью | Быстрый, стаями по 5–8, петляет | Дробовик, шокер, огнемёт — по площади |
| Танкер | 8-й | Крупный серый, светлое кольцо брони | Броня: каждое попадание слабее на 3 (не меньше 1); не отбрасывается | Снайперка, ракеты, горение (броня его не держит) |
| Мозговой | 10-й, не больше 3 | Розовый, большой бледный круг ауры | Жуки в ауре (200 px) на 25 % быстрее и сильнее | Убить первым: снайперка, ракета, удар с орбиты |
| Полубосс | 5, 10, 15-я | Крупный красный, полоска здоровья | Рывки к десантнику, призыв рабочих | Уходить в сторону от рывка |
| Королева | тревога 100 % | Самая крупная, светится | Веер плевков кислотой, призыв свиты | Двигаться поперёк залпа, держаться в радиусе оружия |

### 3.7 Оружие и удар с орбиты

**Слоты.** Стволов — до трёх, стреляет только выбранный (клавиши 1–3, колесо мыши).
Перезарядка остальных идёт в фоне. Забег начинается с MAR; новый ствол приходит
карточкой «Новое оружие» на уровне, пока есть свободный слот, и сразу оказывается в руках.

**Наведение** общее для всех стволов: цель — ближайший жук; ствол добивает её и не
перескакивает на соседей, пока не появится жук вдвое ближе. Полубосс и королева
в приоритете, если ближе 220 px никто не кусает. Снайперская винтовка бьёт
самого живучего жука в радиусе.

| Ствол | Урон | Темп | Дальность | Магазин | Особенность | Модификация (5-й уровень) |
|---|---|---|---|---|---|---|
| MAR | 10 | 8/с | 600 | 40, 1,8 с | По прямой | Подствольный гранатомёт (только находка на карте, 3.5): граната раз в 3 с, 30 урона, радиус 90 |
| Дробовик | 8 × 8 дробин | 1,4/с | 300 | 6, 2,2 с | Веер 35°, отбрасывает | Зажигательная дробь: горение 6/с на 2 с |
| Снайперская винтовка | 60 | 0,8/с | 1100 | 5, 2,5 с | Пробивает 3 | Рельса: пробивает всех на линии |
| Огнемёт | 2 за тик | 12/с | 200 | 60, 2 с | Конус 30°, поджог 3/с на 2 с | Напалм: лужи 8/с на 4 с |
| Тактическая ракетница | 45 | 0,5/с | 800 | 4, 2,5 с | Взрыв радиусом 100, отбрасывает | Кассета: ещё 4 заряда по 20 |
| Мини-турель | 7 | 5/с | 450 | — | Ставится раз в 7 с, работает 20 с, до 3 | По две за раз |
| Шокер | 18 | 1,6/с | 350 | — | Цепь из 4 целей, перескок 170 | Шторм: 8 целей, оглушение 0,5 с |

Урон и темп растут улучшениями ствола и общими улучшениями оружия. Каждое улучшение
ствола поднимает его уровень (1–5); на 5-м предлагается карточка модификации
(кроме MAR — его подствольник находят на карте), и улучшения этого ствола больше
не выпадают — растут только общие.

На карте ствол целится только в жуков, которых видно: лес, стены и закрытые двери
закрывают линию огня, пули и ракеты о них гаснут (ракета рвётся).

**Удар с орбиты** (Пробел): красная метка ставится под курсором, но не дальше
800 пикселей от десантника. Через 1,5 с — взрыв радиусом 220 пикселей и уроном 150
по всем жукам внутри. Перезарядка — 40 с, её показывает полоса в слоте.

### 3.8 Опыт и улучшения

Убитый жук роняет кристалл опыта: рабочий и летающий — 1, стрелок — 2, воин — 3,
танкер — 6, мозговой — 8, полубосс — 40. Кристаллы
в радиусе подбора сами летят к десантнику.

При заполнении полосы опыта игра встаёт на паузу и предлагает три карточки.
Выбор — клавиши 1, 2, 3 или щелчок мышью. Если уровней набрано сразу несколько,
карточки предлагаются подряд. Среди трёх карточек всегда есть хотя бы одна для
оружия и одна пассивная. Улучшения конкретного ствола выпадают, только если он
в слоте. Карточки «Новое оружие» и «Модификация» отмечены золотым.

Цветная полоса сверху карточки — редкость; от неё зависит сила улучшения:

| Редкость | Цвет | Бонус |
|---|---|---|
| Обычное | белый | +7 % |
| Необычное | зелёный | +10 % |
| Редкое | синий | +14 % |
| Эпическое | фиолетовый | +19 % |
| Легендарное | жёлтый | +25 % |
| Мифическое | красный | +33 % |

Улучшение здоровья сразу добавляет прибавку и к текущему здоровью. Пробитие,
дробь и длина цепи шокера берутся не больше трёх раз.

### 3.9 Пауза и статистика

- **Esc** — пауза: «Продолжить», «Начать заново», «Выйти из игры». Повторное
  нажатие Esc снимает паузу.
- **Tab** — статистика десантника (игра на паузе): характеристики,
  время, уровень, образцы ДНК, нанесённый и полученный урон, убитые по видам,
  кто (или что: кислота, кактусы, зыбучий песок) ранил больше всего, стволы с уровнями и модификациями, последние взятые улучшения.
  Повторное нажатие Tab закрывает окно.
- Переключение в другое окно (Alt+Tab) ставит игру на паузу автоматически.

### 3.10 Настройка баланса

Все числа игры хранятся в папке `data` в файлах формата TOML (приложение Б) и
читаются при каждом запуске. Файлы можно править в любом текстовом редакторе
в кодировке UTF-8. Строки после `#` — комментарии.

Пример: сделать рабочих медленнее — в `data/enemies.toml` в разделе `[worker]`
уменьшить `speed`.

Проверить изменение без игры можно ботом-игроком:

```bash
uv run python tools/balance_bot.py --runs 6
```

Бот проходит забеги без окна (десятки секунд на забег) и сообщает, на какой минуте
он погиб или эвакуировался и какого уровня достиг. Биомы он проходит по кругу;
`--biome plain` — ровная земля, `--biome forest` — только густой лес.

### 3.11 Завершение работы

Кнопка «Выйти из игры» в паузе или на экране итогов либо закрытие окна.
Прогресс забега не сохраняется.

## 4. Сообщения оператору

**Сообщения в игре** (под временем, гаснут через 3 с):

| Сообщение | Значение |
|---|---|
| «Биом». Высадка: продержись до эвакуации | Начало забега в биоме |
| Полубосс на подходе | Вышел полубосс (5, 10, 15-я минута) |
| Тревога 100 %: выходит королева | Тревога улья достигла 100 % |
| Королева убита. Челнок идёт — держись в зоне | Началась эвакуация |
| Аптечка: +40 % здоровья | Подобрана аптечка |
| Магнит: весь опыт летит к тебе | Подобран магнит |
| Образец ДНК — собрано N | Подобран образец ДНК |
| Ящик с оружием: «ствол» | Новый ствол в свободном слоте |
| Ящик с оружием: слоты заняты, +30 опыта | Ящик при трёх стволах |
| Найден подствольный гранатомёт для MAR | Подобрана модификация MAR |
| Жуки выломали дверь | Жуки ворвались в постройку, где укрылся десантник |

**Сообщения при запуске** (программа не запускается, текст ошибки — в консоли):

| Текст | Причина и действие |
|---|---|
| `<Класс>: неизвестные ключи [...]` | Опечатка в имени параметра в файле данных — исправить имя |
| `enemies.toml: нет жука <вид>` | Удалён обязательный раздел — вернуть его |
| `upgrades.toml: <id> меняет неизвестную характеристику <имя>` | В улучшении указана характеристика, которой нет в `player.toml` |
| `upgrades.toml: <id> — неверный mode или group` | `mode` — только `mult` или `add`, `group` — `weapon` или `passive` |
| `upgrades.toml: повторяющиеся id` | Два улучшения с одинаковым `id` |
| `upgrades.toml: <id> — неизвестное оружие <id>` | Поле `weapon` ссылается на ствол, которого нет в `weapons.toml` |
| `weapons.toml: нет оружия <id>` | Удалён раздел ствола — вернуть его |
| `player.toml: нет характеристики <ствол>_damage` | У каждого ствола должны быть `<ствол>_damage` и `<ствол>_rate` |
| `session.toml: [[mix]] — неверный вид <вид>` | В составе толпы — несуществующий вид или рабочий/босс |
| `biomes.toml: нет биома <id>` | Удалён раздел биома (`desert`, `forest`, `jungle`, `swamp`) — вернуть его |
| `No module named 'pymunk'` или ошибка сборки pymunk | Запуск под Python 3.14 — нужен Python 3.13 (`uv sync` выберет его сам) |

## Приложение Б. Файлы данных

| Файл | Разделы | Содержание |
|---|---|---|
| `data/player.toml` | `[stats]`, `[caps]`, `[stamina]` | Характеристики десантника, их потолки (уклонение — не больше 60 %), выносливость |
| `data/enemies.toml` | `[scaling]`, раздел на каждого из 8 жуков | Рост силы по минутам; здоровье, скорость, урон, радиус, перезарядка атаки, опыт, цвет и особые параметры (замах, дистанция, броня, аура, стаи, лимит) |
| `data/weapons.toml` | раздел на каждый из 7 стволов, `[orbital]` | Урон, темп, дальность, скорость снаряда, магазин, перезарядка, особые параметры ствола и его модификации (`mod_*`; `mod_found = true` — модификация только находкой на карте); удар с орбиты |
| `data/session.toml` | `[alert]`, `[bosses]`, `[evac]`, `[spawn]`, `[[mix]]`, `[xp]`, `[[rarity]]` | Тревога улья, минуты полубоссов, эвакуация, численность и налёты, состав толпы по минутам, кривая опыта, редкости |
| `data/upgrades.toml` | `[[upgrade]]` | Улучшения: `id`, название, текст, характеристика, режим (`mult` — множитель от редкости, `add` — прибавка `value`), группа, потолок числа взятий, `weapon` — ствол, к которому относится |
| `data/biomes.toml` | `[map]`, `[items]`, раздел на каждый из 4 биомов | Карта: размер и клетка, край, поляна высадки, окно и частота поля путей, темп рубки, прочность двери, замедления (окно, забор, топь, песок), песок и кактусы, расчистка у зоны эвакуации. Находки: лечение аптечки, ДНК за образец, опыт из ящика, число находок. Биом: название, цвета почвы и леса, вид дерева, ударов на дерево, доля и крупность леса, постройки, реки, пятна песка, доля топи |

Расстояния в файлах — в пикселях экрана 1080p, время — в секундах, доли — от 0 до 1.
