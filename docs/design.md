# StarRun — дизайн и баланс

Основа — «Техническое задание на разработку.md». Здесь — решения по вопросам к ТЗ,
предложения концепта и сводка чисел. Источник истины для чисел — `data/*.toml`:
таблицы ниже их пересказывают, при расхождении прав файл данных.

## Решения

| Вопрос | Решение |
|---|---|
| Оружие | Стреляет только выбранное (1–3, колесо мыши); максимум 3; перезарядка остальных — в фоне |
| Новое оружие | Карточкой на уровне, пока есть слот; сразу в руках. Уровень ствола 1–5 его улучшениями, на 5-м — модификация. Подствольник MAR — только находка в постройке (по ТЗ); ящики с оружием — в каждой постройке |
| Карта | Сетка 200 × 200 клеток по 40 px (8000 px), без подгрузки чанков: построек и леса на ней хватает, а NumPy держит всю сетку целиком |
| Препятствия | Лес, стены и вода держат и десантника, и жуков; лес и закрытые двери закрывают линию огня. Жуки обходят препятствия по полю путей, летающие — напрямую |
| Прицел | Автоматически в ближайшего врага в радиусе оружия; цель держится до гибели; босс в приоритете, если рядом никто не кусает |
| Пробел | Слот «Тактический модуль», на старте — удар с орбиты (реализован в этапе 1; остальные модули — предложение, см. ниже) |
| Shift | Бег (запас выносливости) |
| Сессия | Шкала «Тревога улья»: королева выходит при 100 %, не раньше 12-й минуты (реализовано в этапе 1) |
| Открытие оружия | По мере прохождения игры (между забегами) |
| Вид | Настоящее 3D на Arcade GL: наклонная перспективная камера, модели из Blender, инстансинг и скиннинг на GPU. Симуляция остаётся на плоскости; `--2d` включает прежний вид |
| Масштаб | В 3D — 48 px симуляции на метр; интерфейс — 1080 по высоте. В `--2d` мир виден на 1080 px по высоте; ширина — по пропорциям монитора |
| Валюта | «Образцы ДНК» — выпадают с элитных жуков и из контейнеров на карте; тратятся на базе |
| Платформа | Windows |

## Опыт и улучшения

### Тактические приёмы 0.0.13

Три карточки с `fixed = true`: рикошеты MAR (до 2 рангов), AP-снайперка и огненное поле ракетницы
(по одному рангу). Они поднимают уровень оружия и не выпадают после его 5-го уровня;
при этом взаимодействуют с уже имеющимся пробитием, модификациями и пассивными бонусами.
Редкость не изменяет фиксированный эффект; интерфейс помечает их как тактические приёмы.
Числа рикошета и поля — в `weapons.toml`, лимиты — в `player.toml` и `upgrades.toml`.

MAR перенаводится после сквозного пробития; история исключает повторы даже на обратном пути.
AP снимает броню до смерти цели и усиливает последующий огонь MAR/турели.
Огненное поле создаётся только главным взрывом ракеты; кассета не умножает поля.

Визуальный пакет: импульс верхней части тела, гильзы/магазины, вспышки попаданий и броня.
Симуляция выдаёт до 24 событий `hit_feedback` за шаг; частицы показывают до восьми ближайших.
Визуальная случайность использует отдельный генератор, механика забега от неё не зависит.

Начиная с 0.0.12, доступно `[xp].rerolls` обновлений карточек за забег (по умолчанию 3).
Повторный набор по возможности исключает прежние карточки, сохраняя категории оружия
и пассивного улучшения. Обновление не расходует полученный уровень. Предложения
проверяют текущие потолки характеристик; сравнение на карточке считает реальный результат.

Управление: WASD / стрелки, Enter / пробел; R — обновить. Числа и мышь сохранены.

Опыт до следующего уровня: 5 + 3·n + 0,3·n², где n — текущий уровень минус один
(с 1-го на 2-й — 5, с 9-го на 10-й — 49). Опыт за жука: рабочий и летающий — 1,
стрелок — 2, воин — 3, танкер — 6, мозговой — 8, полубосс — 40.

На уровне — три карточки: хотя бы одна для оружия и одна пассивная. Редкость
выпадает на каждую карточку отдельно:

| Редкость | Бонус | Шанс |
|---|---|---|
| Белый (обычный) | +7 % | 55 % |
| Зелёный (необычный) | +10 % | 25 % |
| Синий (редкий) | +14 % | 12 % |
| Фиолетовый (эпический) | +19 % | 5 % |
| Жёлтый (легендарный) | +25 % | 2,5 % |
| Красный (мифический) | +33 % | 0,5 % |

Для прибавок (регенерация, уклонение, пробитие) бонус масштабируется: синяя карточка
даёт вдвое больше белой (0,14 / 0,07).

## Звук и настройки (этап 4)

Визуальная доработка 0.0.12: Exo 2 с плавной фильтрацией глифов, сглаживание краёв
мира, непрерывный материал почвы и воды, прозрачность окружения без пиксельной сетки.
Дома раскрываются в пределах ~220 px от внешнего контура. С 0.0.13 верх стен убирается
полностью, остаётся низкий срез; толщина основных стен снижена с 40 до ~14 px.
Добавлены интерьеры, разметка порогов, тропы и мелкий декор биомов.
Во время рубки оружие не стреляет; цикл 0–1 проходит целиком за `map.chop_every`.
Десантник получил более сдержанные полевые материалы, складки ткани, экипировку,
дыхание, бег с меньшим подскоком и отдачу в стойке. Это процедурная модель,
ориентированная на военную фантастику; фотореалистичный персонаж не заявляется.

Эффекты и фон биомов синтезируются в `tools/sfx/sfx.py`, готовые WAV входят в репозиторий.
Фразы по рации — Piper dmitri, запасной генератор — голос Windows Pavel.
Шаги имеют по три варианта для грунта, песка, топи, дерева и металла; интервал —
72 px фактического пути, поэтому ускорение и замедление меняют ритм.
Перелезание и пауза сбрасывают шаги. Музыка остаётся открытым вопросом.

Настройки экрана и четырёх громкостей доступны из паузы, сохраняются между запусками;
сглаживание требует перезапуска. Сохранения самого забега и мета-прогрессии ещё нет.

## Концепт следующих этапов — ждёт решения заказчика

Полный концепт со схемами и макетом экрана — документ «StarRun — концепт игры»
(Claude Docs, доступ по приглашению автора). Кратко:

- **Тактические задачи** на карте (3 из набора): гнездо, радиомаяк, склад Корпуса,
  выживший. Каждая даёт образцы ДНК и +10 % тревоги — ускоряет выход королевы.
- **Досрочная эвакуация** с 10-й минуты сигнальной шашкой — без бонуса за королеву.
- **Смерть** сжигает половину образцов ДНК.
- **Тактические модули** на пробел: удар с орбиты (старт), реактивный рывок,
  стимулятор, заградительный купол.
- **База** — экран-разрез орбитального корабля: арсенал, оружейная мастерская,
  снаряжение, лаборатория ДНК, стол высадки. Оружие открывается по достижениям.

Референсная сцена (рендер Blender, модели — блокаут): [reference-scene.jpg](reference-scene.jpg).

## Производительность (ТЗ)

300–400 врагов одновременно, не ниже 60 FPS при 1920×1080. Этап 1: 410 жуков
с королевой и HUD — 5,5 мс на кадр (99 % — 10 мс); этап 2 с огнемётом, ракетами
и турелями — 7,3 мс (99 % — 12 мс); этап 3 на карте (густой лес) — 9,0 мс (99 % — 12,6 мс),
из них симуляция 3,3 мс и отрисовка карты ~1,5 мс, см. README.

Сохранённые замеры этапа 4 с 3D и примерно 300 жуками: лес ~11,6 мс,
болото 11,7–12,9 мс (99 % — 15–19 мс). В болоте остаются пики выше бюджета 16,7 мс;
эти данные не являются новым замером после добавления шагов.
